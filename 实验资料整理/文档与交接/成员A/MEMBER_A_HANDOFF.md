## 数据底座与清洗方法

`config/sources.json` 是固定采集清单，稳定 ID 不随排序变化。采集器采用 Python 标准库 urllib，每次顺序抓取公开页面，保存 HTTP 状态、实际 URL、抓取时间、编码、字节数和 SHA256。缓存存在时校验原页面，不重复联网；明确指定 `--refresh` 才重新抓取。

`data/raw/pages/` 保存原始 HTML 和逐页元数据；`data/raw/manifest.json` 保存抓取清单；`data/raw/extracted_records.json` 保存清洗前提取正文。`data/foundation.sqlite` 包含 `raw_documents`、`clean_documents` 两张关联表，保存原文与清洗文本，所有清洗输出都从原始快照重建。

正文提取采用按站点检查过的 BeautifulSoup 选择器。携程支持整体正文和分散的多个正文区块；汽车之家同时读取正文与图注；官网／政府页面选择正文区域。若找不到预期正文，明确报错，不退回整页文本以免把推荐区、导航和页脚当成游记。

清洗使用 NFC、去不可见控制字符、去正文中的 URL、统一空白和换行。保留标点、编号、箭头、条件句及时间信息。段落保留换行，行内链接、加粗和 span 不插入多余换行，避免把景点名称切断。停用和歧义处理作用在实体候选上，不从正文中删词。

检查了空值、重复 ID、精确重复正文、格式和数量；当前未发现精确重复文档。没有把同一文章的不同段落拆成多篇来满足数量。D201 与 D206 是同作者的两篇系列文章，共有部分相同引言，已保留来源偏差说明。

## 实体定义

| 类型 | 定义与边界 | 纳入与排除 |
| --- | --- | --- |
| POI | 明确命名的景区、建筑、园区、门口、古树或服务地点，保留完整原文表述 | 包含历史别称和明确提及的周边地点；不把地铁站中的景点子串当作景点，也不把展览标题中的景点字样直接算作地点 |
| TRANSPORT | 交通方式、工具或表达方式的动作词，如步行、地铁、游船、乘船、共享单车 | 不把“地铁站”单独当作交通方式；不把石制画舫模型直接当作正在使用的交通工具 |
| TIME | 日内时刻、时段，以及明确数量的时长和范围 | 包含上午九点、09:30、下午、半个小时、4-5小时；本实现不覆盖历史年份、朝代、日期、季节或无确定数量的“几天” |

每条实体按位置保留。重叠候选优先最长跨度，完全相同跨度按 POI、TRANSPORT、TIME 顺序处理。带有“左右”的时长可整体纳入；时刻的修饰词通常不纳入，例如“四点左右”保留“四点”。“东门”等局部称呼保留原文，下游结合 scenic 和上下文解析，不在 A 阶段擅自统一名字。

词典有 335 条按景区或外部地点区分的 POI 记录。每一条都记录了实际包含该词的原始页面 ID。Jieba 自定义词典分词样例见 `outputs/jieba_tokenization_samples.json`；最终识别直接由词典与规则生成跨度，不把词性标签自动等同于命名实体类型。

## 验证结果与限制

21 份清洗数据与最终实体通过了字段校验、全局关联、逐条字符切片、分句映射、实体不重叠、原始页面 SHA256、正文 SHA256、SQLite 一致性检查。六项回归与集成测试通过。验证结果见 `outputs/qa/interface_validation.json`。

建立了 30 句问题驱动的暂定参考标注，包含 83 个实体。严格类型与跨度匹配下，micro-F1 为 v1 0.6331、v2 0.8199、v3 0.9308、v4/v5 1.0000。它们已用于改规则，因此只是回归结果，不能作为总体准确率。

另在不同于回归样例的文档中按固定随机种子抽取 18 句，发现历史名字、周边园林和展览标题仍有错误：v4 为 TP=13、FP=2、FN=11，micro-F1=0.6667。随后用这些失败改进了 v5，在同一批文本上得到 TP=24、FP=0、FN=0。这是对已见样本的修复验证，不是新的独立测试。两版结果均保留在 `outputs/qa/postfreeze_review_v4.json` 与 `postfreeze_review_v5.json`。

上述标注由助手复核，均明确标记 `human_confirmed=false`，没有声称已经由组员人工标注。团队应在 `evaluation/human_review.csv` 复核现有样例，也可以使用 `evaluation/team_review_unseen.csv` 中尚未填入答案的 36 句进行真实人工评估。小样本中没有交通实体的类别指标使用 null，不写成 100%。

目前仍有以下局限：词典容易漏掉长尾和未见景点；词典匹配难以完整区分展名、借称和地点；“一点”等歧义排除也可能漏掉确实指时间的少见表达；历史介绍较多的长游记可能拉高部分景点词频；故宫五篇文章来自同作者系列，颐和园也有同作者内容，来源多样性有限。历史别称、同名地点、周边景点的实体识别只代表文本提及，并不证明它们在当前开放区域内。

采集时间与文章发布时间不是同一回事。语料包含 2008 年的游记、2022—2025 年的攻略，以及抓取时的官网导览；陈旧票价、停航、闭馆和路线描述可能与当前情况不同。A 保留来源事实，C 的规划 Agent 应结合来源和时效处理冲突，不能把全部文本当作实时事实。

# 示范用例：一次请求的完整链路

- 请求：`我下午去故宫，只有两个小时，随便看看主要宫殿`
- 后端：llm（LLM 可用=True）
- 耗时：1 ms，共 4 步

## 1. 意图解析（planner.parse_constraints）

```json
{
  "raw": "我下午去故宫，只有两个小时，随便看看主要宫殿",
  "scenic": "故宫博物院",
  "minutes": 120,
  "audience": "通用",
  "pace": "快速",
  "interests": [
    "建筑"
  ],
  "start_hint": "下午"
}
```

缺失关键约束：无

## 2. ReAct 轨迹

### 第 1 步

**思考（Thought）**：用户要去故宫两小时，先看有哪些官方路线和步骤数

**行动（Action）**：`query_route`　参数 `{"scenic": "故宫博物院", "with_steps": false}`

**观察（Observation）**：ok=True，返回 5 条；

- `{"route_id": "RT-GG-OFF-001", "name": "故宫5A景区游览攻略", "step_count": 12}`
- `{"route_id": "RT-GG-OFF-002", "name": "故宫5A景区游览攻略", "step_count": 13}`
- `{"route_id": "RT-GG-OFF-003", "name": "故宫5A景区游览攻略", "step_count": 14}`

### 第 2 步

**思考（Thought）**：再看条件建议里有没有时长相关的取舍

**行动（Action）**：`query_advices`　参数 `{"scenic": "故宫博物院"}`

**观察（Observation）**：ok=True，返回 3 条；全部建议 audience=通用，图谱没有老人/亲子等受众标签

- `{"advice_id": "AD-GG-001"}`
- `{"advice_id": "AD-GG-002"}`
- `{"advice_id": "AD-GG-003"}`

### 第 3 步

**思考（Thought）**：约束齐全，用规划器按 120 分钟截断

**行动（Action）**：`route_plan`　参数 `{"scenic": "故宫博物院", "minutes": 120, "audience": "通用", "pace": "快速"}`

**观察（Observation）**：ok=True，返回 13 条；选 故宫5A景区游览攻略（official，共 13 步，整条估算 114 分钟），按 120 分钟预算截取前 13 步

- `{"minutes_used": 114}`

### 第 4 步

**思考（Thought）**：已拿到规划结果，可以给结论了

**行动（Action）**：`finish` → 生成最终回答

## 3. 最终回答

```
（mock）故宫中轴线约 12 步、估算 105 分钟，余 15 分钟可自由停留。
```

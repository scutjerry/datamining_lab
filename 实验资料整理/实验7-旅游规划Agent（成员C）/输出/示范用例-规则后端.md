# 示范用例：一次请求的完整链路

- 请求：`我下午去故宫，只有两个小时，随便看看主要宫殿`
- 后端：rule（模型 deepseek-flash）
- 耗时：0 ms，共 4 步

## 1. 意图解析（planner.parse_constraints）

```json
{
  "raw": "我下午去故宫，只有两个小时，随便看看主要宫殿",
  "scenic": "故宫博物院",
  "minutes": 120,
  "audience": "通用",
  "pace": "快速",
  "interests": [
    "建筑"
  ],
  "start_hint": "下午"
}
```

缺失关键约束：无

## 2. ReAct 轨迹

### 第 1 步

**思考**：先看 故宫博物院 有哪些现成路线，以及每条路线的步骤数（用来估时长）

**行动**：`query_route`　参数 `{"scenic": "故宫博物院", "with_steps": true}`

**观察**：ok=True，返回 5 条；上游 time_slot/duration_min 缺失（实验3 未落时间维度），步骤只有顺序可依据

- `{"route_id": "RT-GG-OFF-001", "name": "故宫5A景区游览攻略", "step_count": 12}`
- `{"route_id": "RT-GG-OFF-002", "name": "故宫5A景区游览攻略", "step_count": 13}`
- `{"route_id": "RT-GG-OFF-003", "name": "故宫5A景区游览攻略", "step_count": 14}`

### 第 2 步

**思考**：再查该景区的条件性建议，看有没有和当前约束（时长/人群）对得上的取舍提醒

**行动**：`query_advices`　参数 `{"scenic": "故宫博物院"}`

**观察**：ok=True，返回 3 条；全部建议 audience=通用，图谱没有老人/亲子等受众标签

- `{"advice_id": "AD-GG-001"}`
- `{"advice_id": "AD-GG-002"}`
- `{"advice_id": "AD-GG-003"}`

### 第 3 步

**思考**：用户提到“建筑”，在已收录景点里按“殿”过滤一批候选

**行动**：`query_pois_by_scenic`　参数 `{"scenic": "故宫博物院", "keyword": "殿", "in_route_only": true, "limit": 8}`

**观察**：ok=True，返回 8 条；关键词过滤：殿

- `{"name": "文华殿"}`
- `{"name": "太和殿"}`
- `{"name": "养心殿"}`

### 第 4 步

**思考**：约束齐了（120 分钟、通用、快速），交给规划器算路线和时间预算

**行动**：`route_plan`　参数 `{"scenic": "故宫博物院", "minutes": 120, "audience": "通用", "pace": "快速"}`

**观察**：ok=True，返回 13 条；选 故宫5A景区游览攻略（official，共 13 步，整条估算 114 分钟），按 120 分钟预算截取前 13 步

- `{"minutes_used": 114}`

## 3. 最终回答

1. 午门（停留约 6 分钟）

# 示范用例：一次请求的完整链路

- 请求：`我下午去故宫，只有两个小时，随便看看主要宫殿`
- 后端：llm（模型 deepseek-flash）
- 耗时：9771 ms，共 4 步

## 1. 意图解析（planner.parse_constraints）

```json
{
  "raw": "我下午去故宫，只有两个小时，随便看看主要宫殿",
  "scenic": "故宫博物院",
  "minutes": 120,
  "audience": "通用",
  "pace": "快速",
  "interests": [
    "建筑"
  ],
  "start_hint": "下午"
}
```

缺失关键约束：无

## 2. ReAct 轨迹

### 第 1 步

**思考**：景区、时长、节奏都齐了，无需反问。先查故宫候选路线，挑覆盖中轴线主要宫殿的快速路线。

**行动**：`query_route`　参数 `{"scenic": "故宫博物院", "with_steps": true}`

**观察**：ok=True，返回 5 条；上游 time_slot/duration_min 缺失（实验3 未落时间维度），步骤只有顺序可依据

- `{"route_id": "RT-GG-OFF-001", "name": "故宫5A景区游览攻略", "step_count": 12}`
- `{"route_id": "RT-GG-OFF-002", "name": "故宫5A景区游览攻略", "step_count": 13}`
- `{"route_id": "RT-GG-OFF-003", "name": "故宫5A景区游览攻略", "step_count": 14}`

### 第 2 步

**思考**：已看到候选路线，OFF-001 是经典中轴线 12 步。再查一下时间不够时的取舍建议，再交给 route_plan 排 120 分钟行程。

**行动**：`query_advices`　参数 `{"scenic": "故宫博物院", "condition_type": "time"}`

**观察**：ok=True，返回 3 条；全部建议 audience=通用，图谱没有老人/亲子等受众标签

- `{"advice_id": "AD-GG-001"}`
- `{"advice_id": "AD-GG-002"}`
- `{"advice_id": "AD-GG-003"}`

### 第 3 步

**思考**：建议明确说两小时走中轴线即可。现在用 route_plan 生成 120 分钟的快速路线，拿到估算时长与截断结果。

**行动**：`route_plan`　参数 `{"scenic": "故宫博物院", "minutes": 120, "audience": "通用", "pace": "快速"}`

**观察**：ok=True，返回 13 条；选 故宫5A景区游览攻略（official，共 13 步，整条估算 114 分钟），按 120 分钟预算截取前 13 步

- `{"minutes_used": 114}`

### 第 5 步

**思考**：信息已足够：route_plan 给出 120 分钟内的官方中轴线路线与估算，advices 也支持“两小时走中轴线”。可以给最终回答。

**行动**：`finish` → 生成最终回答

## 3. 最终回答

```
【结论】两小时、只想看主要宫殿，走故宫官方中轴线路线（RT-GG-OFF-002，故宫5A景区游览攻略）最合适：13 个点，全程估算约 114 分钟，你的 120 分钟预算刚好够走完，还能剩约 6 分钟。图谱里的建议也明确写着“只有两小时左右建议沿中轴线参观”“走马观花看主要宫殿约两小时”。

【行程清单（按时长估算，每景点按 6 分钟、转场 3 分钟计，不是实测）】
1. 午门（6 分钟）
2. 太和门（+3 分钟转场）
3. 太和殿（+3）
4. 保和殿西庑·天府永藏展（+3）
5. 保和殿东庑·宫阙述往展（+3）
6. 中和殿（+3）
7. 保和殿（+3）
8. 乾清门（+3）
9. 乾清宫（+3）
10. 交泰殿（+3）
11. 坤宁宫（+3）
12. 御花园（+3）
13. 神武门（出园）

【取舍建议】
- 你只想看主要宫殿，可以把第 4、5 步两个庑殿展览（天府永藏展、宫阙述往展）跳过，直接走太和殿→中和殿→保和殿；这样改用官方路线 RT-GG-OFF-001（12 步、估算约 105 分钟），更纯的中轴线，时间也更宽松，剩下约 15 分钟用来拍太和殿、乾清宫。
- 别在单个殿前久留，否则后面会赶；御花园可快速穿行。
- 如果两小时逛得意犹未尽，图谱的建议是可以再往东、西六宫院落里逛（那里曾是妃嫔居所），但这会明显超出预算，需另排时间。

【注意事项】
- 所有时间都是估算值，图谱上游的景点时长为空，没有实测数据，请以现场步行和排队情况为准。
- 图谱没有开放时间/闭馆时间数据，下午入园请自行以故宫官方公告和当日停止入场时间为准，务必预留出园时间。
- 图谱里的游览建议都只有“通用”标签，没有老人/亲子等专门版本；若同行有老人或小孩，节奏要再放慢，这是我按常识补的提示，不是图谱事实。
- 下午光线偏斜，中轴线建筑朝南，太和殿广场拍照建议趁早走完前段。
```

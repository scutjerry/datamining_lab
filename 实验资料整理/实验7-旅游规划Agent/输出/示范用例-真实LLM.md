# 示范用例：一次请求的完整链路

- 请求：`我下午去故宫，只有两个小时，随便看看主要宫殿`
- 后端：llm（模型 deepseek-flash）
- 耗时：9434 ms，共 4 步

## 1. 意图解析（planner.parse_constraints）

```json
{
  "raw": "我下午去故宫，只有两个小时，随便看看主要宫殿",
  "scenic": "故宫博物院",
  "minutes": 120,
  "audience": "通用",
  "pace": "快速",
  "interests": [
    "建筑"
  ],
  "start_hint": "下午"
}
```

缺失关键约束：无

## 2. ReAct 轨迹

### 第 1 步

**思考**：景区、时长、节奏均已知（故宫博物院/120分钟/快速/通用），无需反问。先查故宫的官方路线，看哪条覆盖中轴线主要宫殿。

**行动**：`query_route`　参数 `{"scenic": "故宫博物院", "route_type": "official"}`

**观察**：ok=True，返回 5 条；上游 time_slot/duration_min 缺失（实验3 未落时间维度），步骤只有顺序可依据

- `{"route_id": "RT-GG-OFF-001", "name": "故宫5A景区游览攻略", "step_count": 12}`
- `{"route_id": "RT-GG-OFF-002", "name": "故宫5A景区游览攻略", "step_count": 13}`
- `{"route_id": "RT-GG-OFF-003", "name": "故宫5A景区游览攻略", "step_count": 14}`

### 第 2 步

**思考**：已拿到官方路线 RT-GG-OFF-001（12 步中轴线：午门→太和门→弘义阁→太和殿→中和殿→保和殿→乾清门→乾清宫→交泰殿→坤宁宫→御花园→神武门），最贴合“主要宫殿”。再查时间类的取舍建议，为 120 分钟快速游览做取舍依据。

**行动**：`query_advices`　参数 `{"scenic": "故宫博物院", "condition_type": "time"}`

**观察**：ok=True，返回 3 条；全部建议 audience=通用，图谱没有老人/亲子等受众标签

- `{"advice_id": "AD-GG-001"}`
- `{"advice_id": "AD-GG-002"}`
- `{"advice_id": "AD-GG-003"}`

### 第 3 步

**思考**：建议与用户需求高度吻合（两小时走马观花看主要宫殿、沿中轴线走）。最后用 route_plan 生成 120 分钟快速路线，拿到估算时长与取舍结果。

**行动**：`route_plan`　参数 `{"scenic": "故宫博物院", "minutes": 120, "audience": "通用", "pace": "快速"}`

**观察**：ok=True，返回 13 条；选 故宫5A景区游览攻略（official，共 13 步，整条估算 114 分钟），按 120 分钟预算截取前 13 步

- `{"minutes_used": 114}`

### 第 5 步

**思考**：信息已足够：route_plan 给出 13 步官方中轴线路线，估算 114 分钟，在 120 分钟预算内，且有两条时间建议支撑。可以输出最终行程。

**行动**：`finish` → 生成最终回答

## 3. 最终回答

```
结论：两小时走中轴线正合适。工具按你的 120 分钟预算选了官方路线 RT-GG-OFF-002「故宫5A景区游览攻略」，共 13 步、整条估算约 114 分钟（余约 6 分钟），能完整走完，不用截断。图谱里的两条时间建议也正好对上：「走马观花看主要宫殿约两小时」「只有两小时建议沿中轴线参观」。

行程清单（按官方路线顺序）：
1. 午门（进）
2. 太和门
3. 太和殿
4. 保和殿西庑（天府永藏展）
5. 保和殿东庑（宫阙述往展）
6. 中和殿
7. 保和殿
8. 乾清门
9. 乾清宫
10. 交泰殿
11. 坤宁宫
12. 御花园
13. 神武门（出）

备选：官方路线 RT-GG-OFF-001 是更纯粹的 12 步中轴线版本（估算 105 分钟），不含保和殿东西庑两个展，想多看殿、少进展厅可以换它。

注意事项：
- 时间是估算，不是实测：按「每景点 6 分钟 + 转场 3 分钟」算出来的，图谱里各景点的实际停留时长和时段字段是空的。
- 想更细看，可以把两庑展（第 4、5 步）跳过，省下约 18 分钟补给太和殿、乾清宫。
- 若两小时觉得不过瘾，图谱建议可再逛东、西六宫院落（这属于加时方案，2 小时内做不到）。
- 图谱没有老人/亲子等受众标签，以上按「通用」节奏给出；带老人小孩建议把节奏再放宽，两小时只走午门→三大殿→乾清宫→神武门这段。
```
